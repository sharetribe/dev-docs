# API credit usage reference

This reference lists every billable Sharetribe API endpoint and the
usage type that determines its credit cost. For an overview of how
credits and usage types work, see
[usage-based pricing](/introduction/pricing).

<Callout type="info">
  Rows marked "Per GB" in the Data transfer column additionally bill
  transferred bytes at the data transfer rates listed in the [pricing
  overview](/introduction/pricing#data-transfer-rates).
</Callout>

## Image CDN

Delivery of images through the image CDN is billed as the **Image
download** usage type. No endpoint maps to this type. It covers all
image CDN delivery, billed per request and per GB delivered:

| Image download   | Credits |
| ---------------- | ------- |
| Per request      | 1.5     |
| Per GB delivered | 10,000  |

In addition, the first request for an image within a calendar month is
billed as the **Unique image request** usage type (once per unique image
per month). All requests, including the first, are also billed as image
CDN delivery above. Images that are not requested during a month consume
no credits:

| Unique image request          | Credits |
| ----------------------------- | ------- |
| Per image, per calendar month | 340     |
